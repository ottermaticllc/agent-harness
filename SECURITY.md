# Security

- Install only from `github.com/ottermaticllc/agent-harness`.
- Nothing here sends your code or data anywhere on its own. Skills that call another model (multi-review, codex-loop) send the diff or plan to that provider (OpenAI for Codex, Google for Gemini) under your own account. Each README has a "What it reads, writes and sends" section.
- Nothing here pushes, deletes, sends messages or ends processes without asking you first. sessions-panel's End button asks before it stops a session.
- Found a problem? Open a GitHub issue. For anything sensitive, use the contact link on https://jaredschulman.com instead of a public issue.
